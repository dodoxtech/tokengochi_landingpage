# Landing Page Agent Template — Docs

This vault stores all documentation about the product. Open this `docs/` folder in Obsidian as a vault.

## Navigation

- [[Product Overview]] — product summary, vision, target users
- [[Roadmap]] — development roadmap
- [[Specs MOC]] — feature specifications
- [[Decisions MOC]] — architecture/product decisions (ADR)
- [[Tasks MOC]] — task tracking
- [[Research MOC]] — research, user studies, competitor analysis
- [[Metrics MOC]] — KPIs, metrics, analytics
- [[Changelog]] — product release history

## Folder structure

```
docs/
├── 00-Home/         Vault home page
├── 01-Overview/     Product overview, vision, personas
├── 02-Roadmap/      Roadmap, milestones
├── 03-Specs/        Feature specs (PRD/spec)
├── 04-Decisions/    ADR — architecture & product decisions
├── 05-Tasks/        Task tracking (Todo/ and Done/ subfolders)
├── 06-Research/     User research, competitor & market analysis
├── 07-Metrics/      KPIs, metrics, analytics reports
├── 08-Changelog/    Release history
├── Templates/        Templates for new notes
└── Attachments/       Images, attached files
```

## Quick start

1. Open Obsidian → "Open folder as vault" → select the `docs/` folder.
2. Use Templates (Cmd/Ctrl+P → "Templates: Insert template") when creating new notes in each folder.
3. Set `Templates/` as the templates folder in Settings → Templates.
